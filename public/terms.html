1. What BioAudit is

BioAudit is a security testing tool for Android biometric authentication (for example fingerprint and face ID). It checks how an Android app handles biometric login using static APK analysis, dynamic runtime testing and timing side-channel detection. It does not need root access.

BioAudit is a Final Year Project built by university students. It is a working tool, but it is not a commercial product backed by a company. The app is a Windows desktop program (.exe) that connects to a backend we host ourselves. Dynamic testing also needs ADB (Android Debug Bridge) on your PC and USB debugging switched on for a physical Android device.
